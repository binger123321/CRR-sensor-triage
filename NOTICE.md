# Third-party material

The following files are taken from the public release of MPA-SincNet and are not covered by the MIT licence of this repository:

- `network/model.py`, `network/sincnet.py`, `network/ippa.py` (network code of the published model)
- `resources/checkpoint.pth` (weights of the published model)

Source: Ru Lei, *Data and code for: Multi-sensor microseismic event classification with SNR-based sensor selection and MPA-SincNet model*, Zenodo, 2025, https://doi.org/10.5281/zenodo.15654539, released under the Creative Commons Attribution 4.0 International licence (CC BY 4.0). The files are redistributed unchanged.

The descriptor files in `resources/*.npz` are derived by the scripts of this repository from the waveform data of the same record. The waveform data themselves are not redistributed here; download them from the DOI above.
